## Using a D1 Mini to integrate a Battery-powered Mini-LED String into HASS

*December 22, 2025*

We have various Christmas decorations that use mini-LED strings powered by
AA batteries (typically 2xAA= 3v).  I did not want to manually turn 
these on and off, nor replace batteries every few days.  A D1 mini (at about
$3) seemed like a good way to integrate something with very low power needs
into Home Assistant (HASS).

These are dumb strings (not addressable such as you'd use with a more
sophisticated project with 
<a href="https://github.com/cecat/MyHASS/blob/gh-pages/_posts/2025-01-31-wled.md" target="_blank" rel="noopener noreferrer">WLED</a>).

## Assembly

I wanted this to fit neatly into a small enclosure, so I used a 60x36x25mm
project box
<a href="https://www.amazon.com/YXQ-Waterproof-Electric-Project-Junction/dp/B0716KJRBX/ref=dp_prsubs_d_sccl_2/134-9060794-7504159?pd_rd_w=DekPR&content-id=amzn1.sym.8a163a7b-6a2a-45ae-8510-8d5419efb828&pf_rd_p=8a163a7b-6a2a-45ae-8510-8d5419efb828&pf_rd_r=6Q3MX8PPH8SW3K150VHY&pd_rd_wg=8e05M&pd_rd_r=7d3b4047-d6ac-49c1-9cd5-375e941320c5&pd_rd_i=B0716KJRBX&th=1" target="_blank" rel="noopener noreferrer">like these</a>.
I notched one end for the micro-USB plug,
drilled a small hole at the other end to run the wires to the mini LED strip,
and drilled a hole in the side for the button switch.

I have soldered up boards before only to accidentally fry the D1 mini, so I used headers.
This was also handy because I had to cut the strip board small enough to fit
in the project box, so the only place for connections was under the D1 mini (between the
headers).

### Wiring it Up

Wiring is straightforward as shown in the schematic and breadboard images below.
We are using an NPN transistor and refer to the pins by their functions
(Collector, Base, Emitter -- C, B, and E)). Your transistory data sheet
will also number them 1-3 but the numbering is not consistent across brands.

```
D1 mini 3v3       ------------------------> LED string(+)
NPN Collector (C) ------------------------> LED string (-)

NPN Emitter (E)   ------------------------> D1 mini GND

D1 mini Pin D5    ---> [1k resistor] -----> NPN Base (B)
NPN Base (B)      ---> [100k resistor] ---> D1 mini GND

D1 mini Pin D1    ---> [switch] ----------> D1 mini GND

```

# Set up with HASS

# ☃️ Snowman Lights: D1 Mini Setup Guide

This guide covers setting up a fresh Wemos D1 Mini to control a mini LED string using ESPHome and Home Assistant.

---

## 🛠 Prerequisites
* **Wemos D1 Mini** (ESP8266).
* **Micro-USB Data Cable** (Must support data transfer, not just charging).
* **PC with Chrome or Edge** (Required for the initial web-based flash).

---

## 1️⃣ Phase One: Initial "Birth" (Web Flash)
Before Home Assistant can manage the device, you must install the base ESPHome firmware.

1. Connect the D1 Mini to your computer via USB.
2. Open [web.esphome.io](https://web.esphome.io/).
3. Click **Connect** and select the USB port for your D1 Mini.
4. Click **Install ESPHome** (the generic starter version).
5. Follow the prompts to connect it to your **Wi-Fi**.

---

## 2️⃣ Phase Two: Adoption and Security Keys
Once the device is on your Wi-Fi, Home Assistant will detect it automatically.

1. Open **Home Assistant**.
2. Go to **Settings > Devices & Services**.
3. Click **Configure** on the newly discovered ESPHome device, then click **Adopt**.
4. Once adopted, go to the **ESPHome Dashboard** (left sidebar).
5. Find your new device and click **Edit**.
6. **Copy these unique keys** (you will need them for the next step):
    * Find the line: `api: encryption: key: "..."`
    * Find the line: `ota: - platform: esphome password: "..."`

---

## 3️⃣ Phase Three: Configure Secrets
To keep your configuration clean and secure, move your credentials into the `secrets.yaml` file.

1. In Home Assistant, open the **File Editor** or **VS Code** add-on.
2. Navigate to `/config/esphome/secrets.yaml`.
3. Add these lines at the bottom (using the keys you copied in Phase 2):

```yaml
# Snowman Specific Keys
snowman_api_key: "PASTE_YOUR_API_KEY_HERE"
snowman_ota_password: "PASTE_YOUR_OTA_PASSWORD_HERE"
```

## 4 Phase Four: Apply YAML Code

Return to the **ESPHOME Dashboard**, click **Edie** on your new device, and
replace the **entire** fioe content with the YAML code below. Then click **Save**
then **Install**.  Choose **Wirelessly** and once finished, your new
device will be available for HASS automations.

```yaml
esphome:
  name: snowman
  friendly_name: Snowman Lights

esp8266:
  board: d1_mini

# Standard logger enabled for troubleshooting
logger:

# The encryption key was created during the add device stage in ESPHome
api:
  encryption:
    key: "your-encryption-key-for-your-d1-mini"

ota:
  - platform: esphome
    password: "aca1ee3795fb34ff545b03c4670fd564"

wifi:
  ssid: !secret wifi_ssid
  password: !secret wifi_password

  ap:
    ssid: "Snowman Fallback Hotspot"
    password: "9KPSOTp0serw"

captive_portal:

# Output: LED control via transistor on D5 (GPIO14)
switch:
  - platform: gpio
    pin: 14
    name: "Snowman Lights"
    id: snowman_lights_switch
    restore_mode: ALWAYS_OFF

# Input: Button on D1 (GPIO5)
binary_sensor:
  - platform: gpio
    pin:
      number: 5
      mode: INPUT_PULLUP
      inverted: true
    name: "Snowman Button"
    id: snowman_btn
    filters:
      - delayed_on: 20ms
    on_press:
      then:
        - logger.log: "❄️ Physical Button Pressed on D1!"
        - switch.toggle: snowman_lights_switch

# UI Helper: Keeps the software toggle available in Home Assistant
button:
  - platform: template
    name: "Test Toggle via Software"
    on_press:
      then:
        - switch.toggle: snowman_lights_switch
```
